# ПОЛНОЕ ЗАДАНИЕ НА РАЗРАБОТКУ ППО ModbusDataParser

---

## 1. ОБЩЕЕ ОПИСАНИЕ ЗАДАЧИ

Разработать программное обеспечение (ППО) для чтения и парсинга Modbus регистров из Excel-файлов с целью последующей генерации данных для импорта в SCADA-системы.

---

## 2. ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ

### 2.1 Чтение исходных данных Modbus

#### 2.1.1 Поддерживаемые форматы файлов
- Формат: `.xlsx`, `.xls` (Microsoft Excel)
- Один файл = одна подсистема
- Чтение всех вкладок файла

#### 2.1.2 Типы вкладок

| Тип вкладки | Названия | Описание |
|-------------|----------|----------|
| Параметры интерфейса | `Interface parameters`, `Интерфейс параметры` | Настройки Modbus интерфейса |
| Регистры Modbus | `Register Table`, `Регистр таблица` | Основные сигналы |
| Регистры Slave | `Register Table_Slave_AO`, `Register Table_Slave_AI`, `Register Table_Slave_DO`, `Register Table_Slave_DI` | Сигналы по типам |

#### 2.4.2 Парсинг параметров интерфейса

#### 2.4.3 Парсинг регистров Modbus
- Чтение всех сигналов и их свойств
- Обработка различных типов данных
- Поддержка адресации с битами (Address/Bit)

### 2.5 Маппинг типов данных

#### 2.5.1 Допустимые SCADA типы

| № | Тип | Описание |
|---|-----|----------|
| 1 | BOOL | Булевое значение |
| 2 | WORD | 16-битное беззнаковое целое |
| 3 | INT | 16-битное знаковое целое |
| 4 | UINT | 16-битное беззнаковое целое |
| 5 | UDINT | 32-битное беззнаковое целое |
| 6 | REAL | 32-битное число с плавающей точкой |

#### 2.5.2 Источник Source Data Type
- **Source Data Type** берется ТОЛЬКО из исходных данных Excel (поле `DataType`)
- Автоматически извлекается из загруженных файлов при открытии формы маппинга
- Пользователь НЕ может редактировать Source Data Type

#### 2.5.3 Назначение SCADA Data Type
- Пользователь может назначить SCADA Data Type для каждого Source Data Type
- SCADA Data Type можно:
  1. Выбрать из выпадающего списка (BOOL, WORD, INT, UINT, UDINT, REAL)
  2. Ввести вручную любое значение

#### 2.5.4 Маппинг по умолчанию

| Исходный тип | SCADA тип |
|--------------|-----------|
| BOOL | BOOL |
| 8-Bit Signed | INT |
| 8-Bit Unsigned | WORD |
| 16-Bit Signed | INT |
| 16-Bit Unsigned | WORD |
| 32-Bit Signed | INT |
| 32-Bit Unsigned | UDINT |
| 32-Bit Floating | REAL |
| 64-Bit Floating | REAL |

### 2.6 Генерация шаблона SCADA

#### 2.6.1 Структура шапки выходного файла

Шапка берется из файла-шаблона `Шаблон Modbus SCADA.xls` (первые 3 строки):

**Строка 1:**
```
Cлужебные | | ОБЩЕЕ СВ-ВО | | | | | | | | | | | | | | | | | ...
```

**Строка 2:**
(пустая или служебная)

**Строка 3 (Заголовки):**
```
№ | Статус | Раздел | Марка | Тип объекта | Наименование | Описание | Подпись | Номер | PLC переменная | Период архив | KKS | Доп.параметр | Маска упр. в срезах | Классификатор | Группа событий | КОНТРОЛЛЕР | Адрес | № ресурса или группа | Шаблон
```

#### 2.6.2 Формат генерации полей

| Поле SCADA | Источник | Формат/Правило | Пример |
|------------|----------|----------------|--------|
| № | Автонумерация | 1, 2, 3... | 1 |
| Статус | Статическое | "-" | - |
| Раздел | Статическое | "Mode" | Mode |
| Марка | Генерируется | `_Имя_подсистемы_MB_ТИП_ПолныйАдрес_Тип` | _ASU_MB_HR_40506_REAL |
| Тип объекта | SCADA тип | Из маппинга | REAL |
| Наименование | Генерируется | `MB_ТИП_ПолныйАдрес_Тип` | MB_HR_40506_REAL |
| Описание | Description | Описание переменной | Pressure feedback |
| Подпись | Пусто | "" | |
| Номер | Настраивается | Задается на форме | 0 |
| PLC переменная | PlcTag | Тег ПЛК | PT-9301 |
| Период архив | Настраивается | Задается на форме | 0 |
| **KKS** | **DcsTag** | **Тег РСУ** | **9301-PT-001** |
| Доп.параметр | Пусто | "" | |
| Маска упр. в срезах | Настраивается | Задается на форме | 1 |
| Классификатор | Настраивается | Задается на форме | [ВСЕ] |
| Группа событий | Настраивается | Задается на форме | [ВСЕ] |
| КОНТРОЛЛЕР | Настраивается | Задается на форме | PLC_ASU |
| **Адрес** | **Генерируется** | **Тип_регистра + Адрес_с_ведущими_нулями_до_5_цифр** | **40506** |
| № ресурса или группа | RegisterType | 0, 1, 3 или 4 | 4 |

#### 2.6.3 Формат Марки и Наименования

**Марка:** `_Имя_подсистемы_MB_ТИП_ПолныйАдрес_Тип_данных`

Где:
- `Имя_подсистемы` - задается пользователем на форме
- `MB` - фиксированный префикс (Modbus)
- `ТИП` - тип регистра (HR, IR, CO, DI)
- `ПолныйАдрес` - полный Modbus адрес (например: 40506, 40002, 30025)
- `Тип_данных` - SCADA тип из маппинга (REAL, BOOL, WORD, INT, UINT, UDINT)

**Наименование:** `MB_ТИП_ПолныйАдрес_Тип_данных`

**Примеры:**
| Тип регистра | Адрес/бит | Полный адрес | Марка | Наименование |
|--------------|-----------|--------------|-------|--------------|
| 4 (HR) | 0506 | 40506 | _ASU_MB_HR_40506_REAL | MB_HR_40506_REAL |
| 4 (HR) | 2 | 40002 | _ASU_MB_HR_40002_REAL | MB_HR_40002_REAL |
| 4 (HR) | 0300.1 | 40300 | _ASU_MB_HR_40300_BOOL | MB_HR_40300_BOOL |
| 3 (IR) | 30025 | 30025 | _ASU_MB_IR_30025_REAL | MB_IR_30025_REAL |
| 0 (CO) | 03000 | 03000 | _ASU_MB_CO_03000_BOOL | MB_CO_03000_BOOL |
| 1 (DI) | 3 | 10003 | _ASU_MB_DI_10003_BOOL | MB_DI_10003_BOOL |

#### 2.6.4 Формирование адреса в SCADA таблице (ВАЖНО!)

Адрес в SCADA таблице формируется по стандарту Modbus:

| Тип регистра | Префикс | Диапазон | Формат | Примеры |
|--------------|---------|----------|--------|---------|
| 0 | CO | 00001-09999 | `Адрес_с_ведущими_нулями_до_5_цифр` | 00001, 00500 |
| 1 | DI | 10001-19999 | `10000 + Адрес_с_ведущими_нулями_до_5_цифр` | 10001, 10500 |
| 3 | IR | 30001-39999 | `30000 + Адрес_с_ведущими_нулями_до_5_цифр` | 30001, 30500 |
| 4 | HR | 40001-49999 | `40000 + Адрес_с_ведущими_нулями_до_5_цифр` | 40005, 40506 |

**Примеры:**
| Тип регистра | Адрес/бит | Результат (Адрес) |
|--------------|-----------|-------------------|
| 4 | 0506 | **40506** |
| 4 | 2 | **40002** |
| 4 | 0500 | **40500** |
| 3 | 30001 | **30001** |
| 3 | 25 | **30025** |
| 0 | 00001 | **00001** |
| 0 | 1 | **00001** |
| 1 | 10001 | **10001** |

#### 2.6.5 Определение типа регистра

| RegisterType | Префикс | Тип регистра | Диапазон адресов |
|--------------|---------|--------------|------------------|
| 0 | CO | Coil | 00001 - 09999 |
| 1 | DI | Discrete Input | 10001 - 19999 |
| 3 | IR | Input Register | 30001 - 39999 |
| 4 | HR | Holding Register | 40001 - 49999 |

### 2.8 Графический интерфейс

## 6. ИНСТРУКЦИЯ ПО ЗАПУСКУ

### 6.1 Установка .NET 8.0
Скачать и установить с официального сайта:
```
https://dotnet.microsoft.com/download/dotnet/8.0
```

### 6.2 Создание проекта
```bash
# Создание проекта
dotnet new winforms -n ModbusDataParser -f net8.0-windows
cd ModbusDataParser

# Установка пакетов
dotnet add package EPPlus --version 7.1.2
dotnet add package Newtonsoft.Json --version 13.0.3
```

### 6.3 Сборка и запуск
```bash
# Сборка проекта
dotnet build

# Запуск проекта
dotnet run

# Сборка с оптимизацией
dotnet build -c Release

# Публикация в один файл
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

### 6.4 Поместить файл шаблона
Файл `Шаблон Modbus SCADA.xls` должен находиться в папке с исполняемым файлом приложения.
