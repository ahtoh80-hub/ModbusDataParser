# Полное задание на разработку ППО для чтения данных Modbus и генерации данных для импорта

## 1. Общее описание задачи

Разработать программное обеспечение (ППО) для чтения и парсинга Modbus регистров из Excel-файлов с целью последующей генерации данных для импорта в другие системы.

## 2. Требования к функциональности

### 2.1 Чтение исходных данных
- Чтение данных Modbus из Excel-файлов (формат `.xlsx`)
- Поддержка чтения всех вкладок файла
- Автоматическое определение структуры таблиц
- Обработка файлов с различными названиями вкладок:
  - "Interface parameters" / "Интерфейс параметры"
  - "Register Table" / "Регистр таблица"
  - "Register Table_Slave_*" (AO, AI, DO, DI)

### 2.2 Структура данных
Каждый файл содержит информацию о подсистеме и включает:

#### 2.2.1 Параметры интерфейса (вкладка Interface parameters)
| № п/п | Тип интерфейса | Тип протокола | Slave станция | Slave ID основной | Slave ID резервный | Скорость | Бит четности | Стоп бит | Бит данных | Реверс | Таймаут | Максимальная длина | Примечание |
|-------|----------------|---------------|---------------|-------------------|--------------------|----------|--------------|----------|------------|--------|----------|-------------------|------------|

#### 2.2.2 Регистры Modbus (вкладка Register Table)
| № п/п | Функциональное обозначение по проекту | Тег ПЛК | Описание переменной | Единицы измерения | Шкала | LL | LA | HA | HH | Коэффициенты масштабирования | Тип сигнала | Тип регистра | Адрес/бит | Тип доступа | Тип данных | Код функции | Канал РСУ | Тег РСУ | Функции РСУ | Примечание |
|-------|--------------------------------------|---------|-------------------|------------------|-------|----|----|----|----|------------------------------|-------------|--------------|-----------|-------------|------------|-------------|-----------|---------|------------|------------|

### 2.4 Функции парсинга

Разработать парсер для чтения Excel-файлов с поддержкой:

1. **Автоматическое определение заголовков таблиц**
   - Поиск строки с заголовками по ключевым словам
   - Определение начала данных

2. **Парсинг параметров интерфейса**
   - Чтение всех параметров интерфейса Modbus
   - Сохранение в структурированном виде

3. **Парсинг регистров Modbus**
   - Чтение всех сигналов и их свойств
   - Обработка различных типов данных
   - Поддержка адресации с битами (Address/Bit)

### 2.5 Отображение данных

Разработать графический интерфейс для отображения данных:

1. **Таблица для отображения сигналов**
   - Все поля из Register Table
   - Возможность выбора файла и вкладки
   - Отображение всех сигналов в единой таблице

2. **Элементы управления**
   - Загрузка одного или нескольких файлов
   - Выбор текущего файла из списка
   - Выбор вкладки для просмотра
   - Поиск по тегам, описанию, адресам

3. **Фильтрация**
   - По коду функции Modbus (Function Code)
   - Только сигналы на чтение (Read)
   - Только сигналы на запись (Write)
   - Поиск по тексту

4. **Статусная строка**
   - Информация о загруженных файлах
   - Количество сигналов
   - Текущий файл и вкладка

### 2.6 Генерация данных для импорта

Разработать функции экспорта данных:

1. **Экспорт в CSV для импорта**
   ```
   PLC_Tag,Address,RegisterType,DataType,FunctionCode,AccessType,Description,Unit,SignalType,DCS_Tag,DCS_Functions
   ```

2. **Экспорт карты адресов**
   ```
   Address,Bit,PLC_Tag,Description,DataType,FunctionCode,RegisterType
   ```

3. **Экспорт Modbus маппинга**
   ```
   RegisterType,Address,Bit,PLC_Tag,DataType,AccessType,FunctionCode,Description
   ```

## 5. Примеры использования

### 5.1 Загрузка файлов
```csharp
// Загрузка одного файла
_dataService.LoadFile("Register Table Modbus.xlsx");

// Загрузка нескольких файлов
var files = new[] { "file1.xlsx", "file2.xlsx" };
_dataService.LoadFiles(files);
```

### 5.2 Экспорт данных
```csharp
// Экспорт всех сигналов в CSV
var allSignals = _dataService.GetAllSignals();
var csvData = _dataService.GenerateImportData(allSignals);
File.WriteAllText("export.csv", csvData);

// Экспорт карты адресов
var addressMap = _dataService.GenerateAddressMap(allSignals);
File.WriteAllText("address_map.csv", addressMap);
```

### 5.3 Фильтрация сигналов
```csharp
// Получение сигналов только для чтения
var readOnlySignals = allSignals.Where(s => 
    s.AccessType == "Read" || 
    s.AccessType?.Contains("Read") == true);

// Получение сигналов с конкретным кодом функции
var fc04Signals = allSignals.Where(s => s.FunctionCode == 04);
```
